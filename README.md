# کارنامه Pro — نسخهٔ 1.0

## نصب و اجرا

- از بخش **Releases** همین مخزن نسخهٔ `v1.0` را بگیر، یا فایل `index.html` را مستقیم در مرورگر باز کن (موبایل یا دسکتاپ).
- اولین بارگذاری برای Chart.js و فونت وزیرمتن به اینترنت نیاز دارد. بعد از آن سرویس‌ورکر آن‌ها را کش می‌کند. بدون اینترنت برنامه کار می‌کند، فقط اگر هنوز کش نشده باشند نمودار نمایش داده نمی‌شود و فونت جایگزین می‌آید.
- برای نصب به‌صورت PWA فایل‌های `manifest.json`، `sw.js` و پوشهٔ `icons/` باید کنار `index.html` باشند.

### انتشار روی وب
1. همهٔ فایل‌ها و پوشه‌ها را با همین ساختار روی یک میزبان ایستا (مثلاً GitHub Pages) بگذار.
2. میزبان باید HTTPS داشته باشد؛ باز کردن مستقیم با `file://` برای نصب PWA کافی نیست.
3. بعد از انتشار، سایت را در Chrome یا Edge باز کن و نصب را امتحان کن. در iPhone سایت را در Safari باز کن، از منوی Share گزینهٔ **Add to Home Screen** را بزن.

### بررسی فنی
- در Chrome DevTools بخش **Application** را برای بررسی Manifest و Service Worker باز کن.
- بعد از هر تغییر در فایل‌های برنامه، مقدار `CACHE_VERSION` را در `sw.js` افزایش بده تا کش به نسخهٔ جدید به‌روز شود.
- این بسته یک PWA است، نه APK امضاشده برای فروشگاه. برای Google Play باید نسخهٔ اندرویدی (مثلاً با Bubblewrap یا Capacitor)، کلید امضا و آزمون‌های لازم آماده شود.

## توضیحات عمومی

وب‌اپلیکیشن تک‌فایلی (HTML + CSS + JavaScript، بدون فریم‌ورک و بدون بک‌اند) برای ثبت آزمون‌ها، تحلیل عملکرد، بررسی تک‌تک سؤالات، دفترچه اشتباهات و تصحیح خودکار پاسخ‌برگ.

همهٔ داده‌ها فقط در مرورگر کاربر (`localStorage`) ذخیره می‌شوند. هیچ‌چیز به سرور فرستاده نمی‌شود و عکس پاسخ‌برگ روی همان دستگاه پردازش می‌شود.

کارنامه Pro برای دانش‌آموزی طراحی شده که می‌خواهد بعد از هر آزمون فقط نمره را نبیند، بلکه بفهمد **کجا و چرا** اشتباه کرده است: هر سؤال با مبحث، علت اشتباه و یادداشت ثبت می‌شود و برنامه از روی همین داده‌ها ضعف‌ها و پیشنهاد مطالعه را می‌سازد.

## قابلیت‌ها

- ثبت آزمون به دو حالت: کلی (درسی) یا سؤال به سؤال، با ضریب هر درس و نمرهٔ منفی
- ثبت مبحث، تعریف مبحث، علت اشتباه، یادداشت و وضعیت مرور برای تک‌تک سؤالات
- دفترچه اشتباهات با فیلتر، جست‌وجو و دسته‌بندی بر اساس آزمون، درس، مبحث و علت
- گزارش تحلیلی مستقل برای هر آزمون، همراه با پیشنهاد برنامهٔ مطالعه
- خروجی PDF و Markdown (راست‌چین و فارسی)
- اسکن آفلاین پاسخ‌برگ و پر شدن خودکار وضعیت سؤال‌ها
- داشبورد روند عملکرد با نمودار
- پشتیبان JSON، نسخهٔ ایمنی خودکار و مهاجرت امن داده‌های قدیمی
- کارکرد کامل روی موبایل و دسکتاپ، بدون نیاز به سرور

## جزئیات قابلیت‌ها

### ثبت آزمون
- **دو حالت ثبت:**
  - *کلی (درسی):* برای هر درس تعداد کل، صحیح و غلط.
  - *سؤال به سؤال:* وضعیت هر سؤال (صحیح، غلط، نزده). پایهٔ دفترچه اشتباهات و گزارش تحلیلی است.
- نام و تاریخ آزمون، تعداد سؤال، نمرهٔ منفی (مثلاً هر ۳ غلط ۱ درست)، دروس با بازهٔ سؤال و **ضریب** هر درس.
- هر آزمون مستقل ذخیره می‌شود و با تغییر صفحه یا بستن برنامه از بین نمی‌رود. هنگام ورود، پیش‌نویس خودکار ذخیره می‌شود و دفعهٔ بعد پیشنهاد ادامه می‌دهد.

### اطلاعات هر سؤال
با کلیک روی شمارهٔ سؤال (یا کلید `E` روی سؤال انتخاب‌شده) پنجرهٔ جزئیات باز می‌شود:

| فیلد | توضیح |
|---|---|
| وضعیت | صحیح / غلط / نزده |
| مبحث | با پیشنهاد مباحث قبلاً ثبت‌شده؛ با انتخاب مبحث آشنا، تعریفش خودکار پر می‌شود |
| تعریف مبحث | توضیح موضوع و مفاهیم موردنیاز |
| علت اشتباه | ضعف علمی/مفهومی، بی‌دقتی، اشتباه محاسباتی، کمبود زمان، بدخوانی، فراموشی، حدس، سایر، و دسته‌های دلخواه (از تنظیمات) |
| یادداشت شخصی | متن آزاد |
| نشان‌دار / مرورشده | علامت‌گذاری برای بررسی و وضعیت مرور |

### دفترچه اشتباهات
- مستقیم از اطلاعات آزمون‌ها ساخته می‌شود؛ نسخهٔ تکراری از داده وجود ندارد.
- نمایش غلط‌ها، نزده‌ها و سؤالات نشان‌دار (هر کدام قابل روشن/خاموش).
- فیلتر بر اساس آزمون، درس، مبحث، علت اشتباه و وضعیت مرور، به‌علاوهٔ جست‌وجو.
- دسته‌بندی بر اساس آزمون، درس، مبحث یا علت.
- هر بار ۸۰ مورد نمایش داده می‌شود؛ دکمهٔ «نمایش بیشتر» بقیه را باز می‌کند.

### گزارش تحلیلی هر آزمون
فقط از داده‌های همان آزمون ساخته می‌شود و اطلاعات آزمون‌های دیگر وارد آن نمی‌شود:

- آمار کلی: تعداد و درصد صحیح/غلط/نزده، درصد نهایی با نمرهٔ منفی، رتبه و تراز (اگر وارد شده باشد)
- عملکرد هر درس
- تحلیل مباحث: بیشترین اشتباه، عملکرد خوب، تعداد صحیح/غلط/نزده هر مبحث
- تحلیل علت اشتباهات
- سؤالات نیازمند بررسی (با مبحث، علت، تعریف و یادداشت)
- پیشنهاد مطالعه: مباحث نیازمند مطالعهٔ مجدد، مباحث نیازمند تمرین، اولویت اصلاح، سؤالاتی که باید دوباره حل شوند

پیشنهادها فقط بر اساس داده‌های ثبت‌شده ساخته می‌شوند؛ اگر مبحث یا علت ثبت نشده باشد، گزارش همین را می‌گوید و چیزی حدس نمی‌زند.

**خروجی:** Markdown (دانلود فایل) و PDF. PDF با پنجرهٔ چاپ مرورگر ساخته می‌شود؛ در آن «ذخیره به‌عنوان PDF» را انتخاب کن. فارسی و راست‌چین درست نمایش داده می‌شود.

### داشبورد
نمودار روند، میانگین‌ها، ضعف‌های درسی و تاریخچه. نمودارها با Chart.js رسم می‌شوند.

## اسکن پاسخ‌برگ (آفلاین)

در حالت «سؤال به سؤال»، دکمهٔ «📷 اسکن پاسخ‌برگ (آفلاین)»:

1. عکس پاسخ‌برگ خودت را انتخاب کن.
2. کلید را بده: عکس برگهٔ کلید یا رشتهٔ ارقام (۱ تا ۴؛ `0` یا `-` برای سؤال حذف‌شده).
3. «خواندن برگه» را بزن. تعداد صحیح/غلط/نزده و عکس با دایره‌های رنگی نشان داده می‌شود: سبز درست، نارنجی غلط، قرمز چندگزینه‌ای.
4. «اعمال روی آزمون» وضعیت همهٔ سؤال‌ها را پر می‌کند. مبحث، علت و یادداشت‌هایی که قبلاً نوشته‌ای حفظ می‌شود و بعد از اعمال می‌توانی هر سؤال را اصلاح کنی.

### نحوهٔ تشخیص
قالب پشتیبانی‌شده: **۱۲۰ سؤال، ۴ گزینه**، ۳۰ ردیف در ۴ بلوک، با ۳۰ مربع مشکی در هر یک از دو طرف برگه. شمارهٔ سؤال = `بلوک × ۳۰ + ردیف + ۱`.

1. عکس به طول بیشینهٔ ۱۰۰۰ پیکسل کوچک و خاکستری می‌شود.
2. نور با تقسیم بر میانگین محلی یکنواخت می‌شود.
3. مربع‌های مشکی کناری (اجزای متصل، تیره، مستطیلی) پیدا و اعتبارسنجی می‌شوند: ۳۰ مربع هر طرف، با فاصلهٔ منظم.
4. موقعیت هر حباب با درون‌یابی بین مربع چپ و راست همان ردیف به‌دست می‌آید (جبران کج بودن و پرسپکتیو سبک).
5. تیرگی هر حباب با جدول انتگرالی اندازه‌گیری می‌شود. اگر دو حباب نزدیک به هم تیره باشند، «چندگزینه‌ای» ثبت و نزده حساب می‌شود.

اگر مربع‌ها دیده نشوند، پیام خطای مشخص می‌آید و چیزی ثبت نمی‌شود. برای عکس چرخیده می‌توان زاویه را انتخاب کرد.

### محدودیت‌ها
- فقط همین قالب برگه. قالب دیگر نیاز به تنظیم جداگانهٔ موقعیت حباب‌ها دارد.
- جهت گزینه‌ها پیش‌فرض ۱ تا ۴ از چپ به راست است و در همان پنجره قابل تغییر است؛ با یک برگهٔ شناخته‌شده بررسی کن.
- دقت فقط روی **یک عکس نمونه** سنجیده شده. پیش از اتکا، چند برگهٔ واقعی با نور و زاویهٔ متفاوت امتحان کن.
- عکس برگه ذخیره نمی‌شود، فقط وضعیت سؤال‌ها.
- اگر کلید برای سؤالی نباشد، آن سؤال نزده حساب می‌شود.

## ذخیره‌سازی و پشتیبان

| کلید `localStorage` | محتوا |
|---|---|
| `karnameh_pro.v2` | همهٔ داده‌ها |
| `karnameh_pro.backup` | نسخهٔ ایمنی خودکار |
| `karnameh_pro.draft` | پیش‌نویس آزمونِ نیمه‌کاره |

**نسخهٔ ایمنی** پیش از این عملیات ساخته می‌شود و از تنظیمات قابل بازگردانی است: مهاجرت ساختار قدیمی، بازیابی از فایل، حذف آزمون، صفر کردن داده‌ها.

**بازیابی از فایل JSON** پیش‌فرض «ادغام» است و چیزی پاک نمی‌کند. جایگزینی فقط با تأیید انجام می‌شود.

> داده‌ها فقط در مرورگر هستند. پاک کردن داده‌های مرورگر یا عوض کردن دستگاه یعنی از دست رفتن همه‌چیز. مرتب پشتیبان JSON بگیر.

وضعیت ذخیره (✓ ذخیره شد / ⚠ ذخیره نشد) بالای صفحه نمایش داده می‌شود.

### ساختار داده (schema 3)

```json
{
  "schema": 3,
  "exams": [{
    "id": "…", "name": "سنجش ۱", "date": "2026-11-13", "createdAt": 0,
    "mode": "detail", "total": 120, "penalty": 0.3333,
    "ranges": [{ "name": "ریاضی", "from": 1, "to": 60, "coef": 2 }],
    "answers": [{ "s": "w", "r": "careless", "t": "مبحث", "td": "تعریف", "comment": "یادداشت", "f": 1, "d": 1 }],
    "rank": "", "level": "", "note": ""
  }],
  "templates": [], "customReasons": [{ "id": "x_…", "label": "استرس آزمون" }],
  "settings": { "lang": "fa", "theme": "dark", "penalty": 0.3333, "goal": 65 }
}
```

- `s`: `c` صحیح، `w` غلط، `b` نزده. `r`: کلید علت. `f`: نشان‌دار. `d`: مرورشده. `t`/`td`: مبحث و تعریف.
- آزمون‌های حالت «کلی» به‌جای `ranges`/`answers` از `subjects: [{ name, count, c, w, coef }]` استفاده می‌کنند.
- ساختار قدیمی (`schema` قدیمی‌تر یا بدون آن) هنگام بارگذاری خودکار مهاجرت می‌کند؛ هیچ فیلدی حذف نمی‌شود و فیلدهای ناشناخته حفظ می‌شوند.

## English

**Karnameh Pro v1.0** is a single-file, offline-first web app (HTML/CSS/JS, no framework, no backend) for logging exams, analysing performance, reviewing every question, keeping a mistake notebook, and grading answer sheets from a photo. All data stays in the browser (`localStorage`).

### Package contents
- `index.html`: main application
- `manifest.json`: installation metadata for mobile and desktop
- `sw.js`: service worker for asset caching and basic offline support
- `icons/`: app icons
- `CHANGELOG.md`: release notes

### Features
- Two entry modes: per-subject totals, or question-by-question
- Per-question topic, topic definition, mistake reason, personal note, review status
- Mistake notebook with filters, search and grouping
- Per-exam analytical report with a study plan, exported as PDF and Markdown (RTL / Persian)
- Offline answer-sheet scanner (120 questions, 4 options)
- JSON backup, automatic safety snapshot, safe migration of older data

### Deploy
Upload all files to an HTTPS static host, keep the directory structure, then test installation in Chrome/Edge (iPhone: Safari → Share → Add to Home Screen). After changing app files, increment `CACHE_VERSION` in `sw.js`.
